# 3D Coffee Mug Design

A parametric 3D model of a ceramic coffee mug designed in SOLIDWORKS with custom text embossing.

## Preview
![Coffee Mug Render](./Coffee%20Mug.JPG)

## Design Features
- **Base Body:** Revolved Boss/Base
- **Handle:** Swept Boss/Base
- **Ergonomics:** Fillets applied on lip and base edges
- **Branding:** Surface text embossing

## Files
- `Coffee Mug.SLDPRT` — Native SOLIDWORKS part file
- `Coffee Mug.JPG` — Rendered view
